# نیرو · Niro Desk

دفتر دسکتاپ و آفلاین مدیریت منابع انسانی با رابط فارسی و انگلیسی. بانک اصلی یک فایل محلی XLSX است.

## نصب روی ویندوز

فایل `NiroDesk-Windows-x64-with-source.zip` را از بخش Releases گیت‌هاب بگیرید و از حالت فشرده خارج کنید. پوشهٔ نسخه شامل `NiroDesk-Setup-x64.exe`، فایل SHA-256 و پوشهٔ `Source` با سورس کامل برنامه، دارایی‌های گرافیکی، فونت‌ها، تست‌ها و دستور ساخت نصاب است. نصاب برای ویندوز ۱۰ (۱۸۰۹ به بعد) و ۱۱ نسخهٔ ۶۴ بیتی ساخته شده است و میان‌بر **Niro Desk** را روی دسکتاپ و منوی Start قرار می‌دهد. اجرای برنامه به اینترنت، نصب Python یا نصب Excel وابسته نیست. نسخهٔ انتشار فعلی امضای کد ویندوز ندارد.

1. فایل بانک خودتان را در یک پوشهٔ محلی نگه دارید.
2. در برنامه **اتصال فایل اکسل** را بزنید و فایل را انتخاب کنید. در **تنظیمات** می‌توانید شیت فعال را تغییر دهید یا یک بانک خالی بسازید.
3. تغییرات ذخیره‌شده در اکسل روی همان فایل ظرف چند ثانیه در برنامه ظاهر می‌شوند. برنامه آخرین خواندن موفق و مشکل‌های دسترسی را نمایش می‌دهد.

## کار با بانک و گزارش‌ها

- **داشبورد** تعداد نفرات، جذب‌ها و خروج‌ها، نمودار روند و توزیع وضعیت اشتغال را نشان می‌دهد. بازه‌های ۳۰، ۹۰ و ۳۶۵ روزه برای رویدادهای تاریخ‌دار قابل انتخاب‌اند. در نبود ستون تاریخ خروج، تعداد خروج از وضعیت ثبت‌شدهٔ کارکنان به دست می‌آید.
- در **داشبورد ← انتخاب نمودارها**، ستون‌های دلخواه شیت فعال را علامت بزنید. هر ستون یک کارت حلقه‌ای با مجموع نفرات و تعداد هر مقدار دارد. اگر ستون بیش از پنج مقدار داشته باشد، مقادیر کم‌تکرار در «سایر مقادیر» جمع می‌شوند و دکمهٔ **همهٔ مقادیر** جدول کامل را نشان می‌دهد. برای برداشتن یک کارت، تیک ستون را در همان پنجره بردارید. انتخاب‌ها برای هر شیت جداگانه ذخیره می‌شوند و نمودارها پس از ذخیرهٔ فایل اکسل خودکار به‌روز می‌شوند.
- فیلدهای تاریخ فرم با تقویم شمسی و میلادی باز می‌شوند و می‌توانید روز جاری را انتخاب کنید. هشت فیلد پرکاربرد مثل وضعیت اشتغال و رتبه به‌صورت پیش‌فرض کشویی هستند. در **تنظیمات ← فهرست‌های کشویی فرم** می‌توانید این انتخاب را برای همهٔ ستون‌های شیت تغییر دهید.
- فیلتر فهرست پرسنل و مقدار شرط گزارش از مقادیر یکتای ستون انتخاب‌شده پر می‌شوند. عنوان گزارش، نام پیشنهادی فایل خروجی است.
- همهٔ ستون‌های دارای عنوان در جدول فعال قابل جست‌وجو، ویرایش و انتخاب برای گزارش هستند. در یک شیت بدون جدول، اولین ردیف دارای عنوان مبنای خواندن است. در شیت چندجدولی، جدول اول بر اساس موقعیت خوانده می‌شود.
- در فرم افزودن، ویرایش یا حذف، **فقط در برنامه** یا **برنامه و بانک اکسل** را انتخاب کنید. برای نوشتن مستقیم، بانک باید در Excel بسته و قابل نوشتن باشد. حذف مستقیم سلول‌های رکورد را خالی می‌کند تا قالب و سایر ردیف‌ها باقی بمانند.
- تغییر محلی هر فیلد تا زمانی باقی می‌ماند که همان فیلد در فایل تغییر کند. حذف محلی رکورد را از دید همین کاربر پنهان می‌کند. حذف در فایل، رکورد وابسته را از فهرست برنامه برمی‌دارد. از تنظیمات می‌توانید تغییرات محلی شیت را بازنشانی کنید.
- برای اتصال پایدار تغییرات محلی پس از جابه‌جایی ردیف‌ها، «کد پرسنلی» یا «کد ملی» یکتا وارد کنید. اگر ردیف بعد از تغییر فایل با اطمینان شناسایی نشود، تغییر محلی آن معلق می‌ماند. اتصال و سابقهٔ محلی هر بانک به مسیر فایل و شیت آن وابسته است.
- در **گزارش‌ساز** می‌توانید چند شرط را با «همه» یا «حداقل یکی» ترکیب کنید، تنها ستون‌های انتخابی را خروجی بگیرید و قالب اداری یا مدرن را انتخاب کنید. پیش‌نمایش برای سرعت حداکثر ۱۲۰ رکورد نشان می‌دهد. خروجی هر چهار فرمت `.xlsx`، `.docx`، `.pptx` و `.csv` تمام نتایج فیلتر را در بر می‌گیرد. قالب‌های بصری برای سه فرمت آفیس هستند و CSV دادهٔ متنی ساده است.
- در **تنظیمات ← شخصی‌سازی ← طرح‌های گرافیکی**، ۱۹ طرح تصویری با پیش‌نمایش قابل انتخاب‌اند. هر طرح تصویر داشبورد، رنگ‌بندی و نمودارها را تغییر می‌دهد. در همان بخش، ۳۲ گزینهٔ فونت با پیش‌نمایش فارسی و انگلیسی و ۱۲ پوستهٔ رنگی در دسترس‌اند. برنامه انتخاب‌ها را برای اجرای بعدی ذخیره می‌کند.
- وقتی فهرست کشویی بسته است، چرخ موس مقدار انتخاب‌شده را عوض نمی‌کند. در فهرست باز می‌توانید بین گزینه‌ها پیمایش کنید و با کلیک یا صفحه‌کلید انتخاب کنید.
- تنظیمات و تغییرات محلی در پروفایل همان کاربر ذخیره می‌شوند. در ویندوز، متن تغییرات محلی و نسخهٔ بازیابی با Windows DPAPI همان کاربر محافظت می‌شوند. بازیابی فایل قبلی از تنظیمات به مسیر دیگری ممکن است. بانک اصلی و گزارش‌های صادرشده فایل‌های عادی هستند و با مجوزهای پوشهٔ انتخابی نگهداری می‌شوند.

## تحلیل و حضور تربیت بدنی

- در **تحلیل و مقایسه ← انتخاب شاخص‌ها**، چند شاخص را هم‌زمان انتخاب کنید. هر کارت گزینهٔ نمودار ستونی، خطی، مساحتی و جدول دارد. نمودار حلقه‌ای برای شمارش‌های تجمیعی یا درصدهای قابل تفکیک در دسترس است. برای مقایسهٔ مشترک از گروه‌هایی مانند مدیریت، نوع عضویت، تحصیلات، ردهٔ سنی یا نفر به نفر استفاده کنید. برای واحدهای متفاوت و چند گروه، بیشترین مقدار هر شاخص روی نمودار مشترک معادل ۱۰۰٪ است. جدول و راهنمای نمودار مقادیر واقعی با واحد را نشان می‌دهند.
- بازهٔ **دو سال گذشته** و **بازهٔ دلخواه** از جمله انتخاب‌ها هستند. تاریخ ورود به سازمان در این بازه معیار جذب است. روند خروج از تاریخ خروج خوانده می‌شود. خروج‌های دارای وضعیت خروج و بدون تاریخ جداگانه برای کل فهرست گزارش می‌شوند.
- برنامه مقدار سابقهٔ ثبت‌شده در اکسل را می‌خواند. برای ردیف‌های بدون مقدار سابقه، از تاریخ معتبر ورود به سازمان و در صورت ثبت، تاریخ خروج استفاده می‌کند. رضایت شغلی میانگین پاسخ‌های معتبر از ۱۰۰ است. برای عددهای خام، مقیاس ۰ تا ۱۰۰ یا ۱ تا ۵ را در **ستون‌های داده** مشخص کنید. مرخصی به تعداد دفعات و مدت تأخیر به دقیقه خوانده می‌شود.
- برنامه ستون‌های معمول مدیریت، عضویت، تاریخ تولد، سطح تحصیلات و سایر شاخص‌ها را خودکار می‌شناسد. در **ستون‌های داده** می‌توانید ستون دلخواه را معرفی کنید. برای تکمیل داده‌ها، **ساخت شیت شاخص‌ها در اکسل** شیت «شاخص‌های پرسنلی» را به همان بانک اضافه می‌کند. کد پرسنلی یا ملی هر ردیف باید با یک نفر یکتا در شیت اصلی منطبق باشد. می‌توانید مقدار مدیریت، رضایت، سابقه، خروج، مرخصی و تأخیر را در همان شیت وارد کنید. پس از ذخیره در اکسل، تحلیل به‌روز می‌شود.
- در **حضور تربیت بدنی**، تاریخ جلسه، عنوان و وضعیت حاضر، غایب یا غیبت موجه را برای فرد ثبت کنید. اولین ثبت، شیت «حضور تربیت بدنی» را در همان بانک ایجاد می‌کند. ذخیره و ویرایش حضور از داخل برنامه به فایل قابل نوشتن و بسته در Excel نیاز دارد. برای ثبت حضور، کد پرسنلی یا ملی یکتا لازم است. نرخ حضور درصد «حاضر» از کل ثبت‌های معتبر بازه است.

## داشبورد تعاملی و امور پرسنل

- بخش رنگی حلقه یا سطر کنارش را انتخاب کنید. انتخاب از چند کارت هم‌زمان روی نفرات اعمال می‌شود. **نفرات انتخاب‌شده** نتیجه را باز می‌کند و می‌توانید همان فیلترها را به **فهرست نفرات** یا **گزارش‌ساز** بفرستید. در **چیدمان داشبورد** کارت‌های انتخابی را با کشیدن مرتب کنید، کارت تمام‌عرض را علامت بزنید و برای هر موقعیت چیدمانی با نام دلخواه ذخیره کنید.
- **بستهٔ جلسه** در داشبورد، خلاصهٔ Word، فایل اکسلِ نفرات و تصویر نمودارهای مربوط را در یک ZIP می‌گذارد. بازهٔ تاریخ، روند جذب و خروج را مشخص می‌کند. با انتخاب یک ستون تاریخ، فهرست بسته هم به همان بازه محدود می‌شود.
- **امور پرسنل ← پروندهٔ پرسنلی**، اطلاعات شیت فعال و سوابق انتقال، ارتقا، آموزش، قرارداد و مدارک را کنار هم نشان می‌دهد. سوابق و پیوست‌ها در فضای محلی همان پروفایل نگهداری می‌شوند و در ویندوز با DPAPI محافظت می‌شوند. کد یکتای پرسنلی یا ملی پیوند پایدار پرونده را هنگام تغییر سایر سلول‌ها حفظ می‌کند. برای ردیف بدون کد، برنامه فقط یک ردیف یکتا با همان مشخصات را به پروندهٔ محلی وصل می‌کند.
- در **سررسیدها** ستون‌های تاریخ و فیلدهای الزامی را انتخاب کنید و فاصلهٔ یادآوری را به روز مشخص کنید. تاریخ‌های پروندهٔ پرسنلی هم بررسی می‌شوند. برنامه هنگام کار با بانک، موارد نیازمند پیگیری را در بخش امور پرسنل نشان می‌دهد.
- در **شیفت، تردد و مرخصی** ساعات شیفت عمومی و فردی، مهلت تأخیر، روزهای کاری و تعطیلی‌ها را تعیین کنید. فایل XLSX یا CSV دارای «کد پرسنلی، تاریخ، ورود، خروج» یا «کد پرسنلی، زمان تردد» را وارد کنید. کد باید با رکورد یکتای بانک منطبق باشد. گزارش اول و آخرِ تردد از زمان‌های همان روز به‌دست می‌آید. برای شیفت شب از ستون‌های ورود و خروج در یک ردیف استفاده کنید. مقادیر ساعت به شکل `08:30` و تاریخ‌ها به شکل شمسی یا میلادی پذیرفته می‌شوند. برای ماندهٔ مرخصی، سهمیهٔ ساعتی همان بازهٔ انتخابی را ثبت کنید.
- **کنترل کیفیت بانک** ردیف‌های همسان، کدهای خالی یا تکراری، تاریخ‌های نامعتبر و تعداد تغییرات محلی نیازمند تطبیق را نشان می‌دهد. اصلاح گروهی، مقدار قدیم و جدید را پیش از نوشتن نشان می‌دهد. برنامه پیش از تغییر اکسل یک نسخهٔ تاریخ‌دار می‌گیرد. از **نسخه‌های بازیابی** می‌توانید یک کپی اکسل در مسیر دلخواه ذخیره کنید.
- از **حساب‌ها و دسترسی‌ها** ابتدا حساب مدیر بسازید. برای حساب‌های دیگر نقش خواننده یا ویرایشگر، مجوز مشاهدهٔ فیلدهای حساس و مجوز خروجی را مشخص کنید. تغییرات داخل برنامه با زمان و نام کاربر در **تاریخچهٔ تغییرات** ثبت می‌شوند. مجوزهای ویندوز، دسترسی مستقیم به فایل‌های اکسل و پوشهٔ داده را تعیین می‌کنند.
- در **جست‌وجوی فارسی آفلاین**، عبارتی مثل «کد پرسنلی خالی» یا «قراردادی‌های مالی که قراردادشان تا ۳۰ روز دیگر تمام می‌شود» وارد کنید. فیلترهای پیشنهادی با ستون‌ها و مقادیر شیت فعال ساخته می‌شوند. پیش از انتقال به فهرست یا گزارش‌ساز، آن‌ها را بررسی و ویرایش کنید. جست‌وجو از عبارت‌های پشتیبانی‌شده برای مقدار گروه، خالی بودن، مقایسهٔ عددی و بازهٔ تاریخ استفاده می‌کند.

## رفتار بانک‌های خاص

متن تغییرات نوشته‌نشده در حافظهٔ Excel قابل مشاهده نیست. برنامه پس از ذخیره یا AutoSave همگام می‌شود. فرمول‌ها و Power Query فقط در Excel اجرا یا تازه‌سازی می‌شوند. برنامه مقدار ذخیره‌شدهٔ فرمول را می‌خواند و بخش‌های اتصال Power Query بانک را هنگام ویرایش حفظ می‌کند. اگر Excel جدول Power Query را از منبع اصلی آن تازه‌سازی کند، نتیجهٔ آن تازه‌سازی مبنای فهرست خواهد بود. برای جدول‌های دارای ردیف جمع یا چیدمان خاص، در صورت پر بودن جدول ابتدا در Excel یک ردیف خالی ایجاد کنید.

## Run from source

Use Python 3.12 or 3.13. The interface uses Qt Widgets.

~~~sh
python -m venv .venv
# Activate .venv for your platform.
python -m pip install -r requirements.txt
python -m niro
python -m unittest discover -s tests -v
~~~

For a headless UI check on Linux, run `QT_QPA_PLATFORM=offscreen python -m niro --self-test`. The runtime and all input needed after installation are local. The source checkout and installer contain no personnel workbook.

Build the offline Windows x64 installer with NSIS 3.11 or later and Python.

~~~sh
python packaging/build_windows.py --makensis /path/to/makensis
~~~

A version tag such as `v2.0.0` triggers the Windows release workflow. It builds the installer, archives it with the tagged source, verifies the installer from that archive on Windows, and publishes the ZIP, standalone executable, and checksum.
