# نیرو · Niro Desk

دفتر دسکتاپ و آفلاین مدیریت منابع انسانی با رابط فارسی و انگلیسی. بانک اصلی یک فایل محلی XLSX است.

## نصب روی ویندوز

فایل NiroDesk-Setup-x64.exe را از بخش Releases گیت‌هاب دریافت و اجرا کنید. نصاب برای ویندوز ۱۰ (۱۸۰۹ به بعد) و ۱۱ نسخهٔ ۶۴ بیتی ساخته شده است و میان‌بر **Niro Desk** را روی دسکتاپ و منوی Start قرار می‌دهد. اجرای برنامه به اینترنت، نصب Python یا نصب Excel وابسته نیست. نسخهٔ انتشار فعلی امضای کد ویندوز ندارد و فایل SHA-256 کنار نصاب منتشر می‌شود.

1. فایل بانک خودتان را در یک پوشهٔ محلی نگه دارید.
2. در برنامه **اتصال فایل اکسل** را بزنید و فایل را انتخاب کنید. در **تنظیمات** می‌توانید شیت فعال را تغییر دهید یا یک بانک خالی بسازید.
3. تغییرات ذخیره‌شده در اکسل روی همان فایل ظرف چند ثانیه در برنامه ظاهر می‌شوند. برنامه آخرین خواندن موفق و مشکل‌های دسترسی را نمایش می‌دهد.

## کار با بانک و گزارش‌ها

- **داشبورد** تعداد نفرات، جذب‌ها و خروج‌ها، نمودار روند و توزیع وضعیت اشتغال را نشان می‌دهد. بازه‌های ۳۰، ۹۰ و ۳۶۵ روزه برای رویدادهای تاریخ‌دار قابل انتخاب‌اند. در نبود ستون تاریخ خروج، تعداد خروج از وضعیت ثبت‌شدهٔ کارکنان به دست می‌آید.
- فیلدهای تاریخ فرم با تقویم شمسی و میلادی باز می‌شوند و می‌توانید روز جاری را انتخاب کنید. هشت فیلد پرکاربرد مثل وضعیت اشتغال و رتبه به‌صورت پیش‌فرض کشویی هستند. در **تنظیمات ← فهرست‌های کشویی فرم** می‌توانید این انتخاب را برای همهٔ ستون‌های شیت تغییر دهید.
- فیلتر فهرست پرسنل و مقدار شرط گزارش از مقادیر یکتای ستون انتخاب‌شده پر می‌شوند. عنوان گزارش، نام پیشنهادی فایل خروجی است.
- همهٔ ستون‌های دارای عنوان در جدول فعال قابل جست‌وجو، ویرایش و انتخاب برای گزارش هستند. در یک شیت بدون جدول، اولین ردیف دارای عنوان مبنای خواندن است. در شیت چندجدولی، جدول اول بر اساس موقعیت خوانده می‌شود.
- در فرم افزودن، ویرایش یا حذف، **فقط در برنامه** یا **برنامه و بانک اکسل** را انتخاب کنید. برای نوشتن مستقیم، بانک باید در Excel بسته و قابل نوشتن باشد. حذف مستقیم سلول‌های رکورد را خالی می‌کند تا قالب و سایر ردیف‌ها باقی بمانند.
- تغییر محلی هر فیلد تا زمانی باقی می‌ماند که همان فیلد در فایل تغییر کند. حذف محلی رکورد را از دید همین کاربر پنهان می‌کند. حذف در فایل، رکورد وابسته را از فهرست برنامه برمی‌دارد. از تنظیمات می‌توانید تغییرات محلی شیت را بازنشانی کنید.
- برای اتصال پایدار تغییرات محلی پس از جابه‌جایی ردیف‌ها، «کد پرسنلی» یا «کد ملی» یکتا وارد کنید. اگر ردیف بعد از تغییر فایل با اطمینان شناسایی نشود، تغییر محلی آن معلق می‌ماند. اتصال و سابقهٔ محلی هر بانک به مسیر فایل و شیت آن وابسته است.
- در **گزارش‌ساز** می‌توانید چند شرط را با «همه» یا «حداقل یکی» ترکیب کنید، تنها ستون‌های انتخابی را خروجی بگیرید و قالب اداری یا مدرن را انتخاب کنید. پیش‌نمایش برای سرعت حداکثر ۱۲۰ رکورد نشان می‌دهد. خروجی هر چهار فرمت `.xlsx`، `.docx`، `.pptx` و `.csv` تمام نتایج فیلتر را در بر می‌گیرد. قالب‌های بصری برای سه فرمت آفیس هستند و CSV دادهٔ متنی ساده است.
- در **شخصی‌سازی** نام برنامه، جهت و زبان رابط، ۱۲ گزینهٔ فونت و ۱۲ پوستهٔ روشن و تیره قابل تنظیم‌اند.
- تنظیمات و تغییرات محلی در پروفایل همان کاربر ذخیره می‌شوند. در ویندوز، متن تغییرات محلی و نسخهٔ بازیابی با Windows DPAPI همان کاربر محافظت می‌شوند. بازیابی فایل قبلی از تنظیمات به مسیر دیگری ممکن است. بانک اصلی و گزارش‌های صادرشده فایل‌های عادی هستند و با مجوزهای پوشهٔ انتخابی نگهداری می‌شوند.

## رفتار بانک‌های خاص

متن تغییرات نوشته‌نشده در حافظهٔ Excel قابل مشاهده نیست. برنامه پس از ذخیره یا AutoSave همگام می‌شود. فرمول‌ها و Power Query فقط در Excel اجرا یا تازه‌سازی می‌شوند. برنامه مقدار ذخیره‌شدهٔ فرمول را می‌خواند و بخش‌های اتصال Power Query بانک را هنگام ویرایش حفظ می‌کند. اگر Excel جدول Power Query را از منبع اصلی آن تازه‌سازی کند، نتیجهٔ آن تازه‌سازی مبنای فهرست خواهد بود. برای جدول‌های دارای ردیف جمع یا چیدمان خاص، در صورت پر بودن جدول ابتدا در Excel یک ردیف خالی ایجاد کنید.

## Run from source

Use Python 3.12 or 3.13. The interface uses Qt Widgets.

~~~sh
python -m venv .venv
# Activate .venv for your platform.
python -m pip install -r requirements.txt
python -m niro
python -m unittest discover -s tests -v
~~~

For a headless UI check on Linux, run `QT_QPA_PLATFORM=offscreen python -m niro --self-test`. The runtime and all input needed after installation are local. The source checkout and installer contain no personnel workbook.

Build the offline Windows x64 installer with NSIS 3.11 or later and Python.

~~~sh
python packaging/build_windows.py --makensis /path/to/makensis
~~~

A version tag such as `v1.1.0` triggers the Windows release workflow. It builds the installer, installs it on Windows, runs the installed application smoke test, and publishes the executable and checksum.
